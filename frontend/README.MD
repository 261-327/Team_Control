# Интерфейс Сипи

Next.js 16 / React 19 / TypeScript. Интерфейс подключён к Django JSON API; демовхода, фиктивных проектов и локальной базы приложения больше нет.

Из корня репозитория запусти `./start.sh`, затем открой http://127.0.0.1:3000. Docker не нужен. Скрипт поднимает Django и Next.js; данные сохраняются в SQLite. Полная инструкция и Docker Compose — в [README проекта](../README.md). Для общего сервера команды — [инструкция деплоя](../deploy/README.md).

Если Django уже запущен отдельно:

```sh
npm ci
npm run dev
```

`DJANGO_API_URL` задаёт адрес Django для серверного прокси Next.js, по умолчанию `http://127.0.0.1:8000`. Пример — `.env.example`. Браузер обращается только к `/api` на адресе интерфейса. Сессия хранится в HttpOnly cookie Django, CSRF включён для всех изменений, включая вход и регистрацию.

Доступны личные задачи, проекты, поиск и вступление, создание проекта, доска со сменой статусов и перетаскиванием, карточка задачи с историей и комментариями, команда и приглашения, материалы, настройки колонок, календарь, обзор команд и профиль. Дополнительные колонки из старого Django сохраняются на доске.

Панель помощника справа сохранена. Ближайшие сроки берутся из Django; внешняя модель пока не подключена, и интерфейс прямо об этом сообщает.

```sh
npm run lint
npx tsc --noEmit
npm run build
npm run format:check
```
