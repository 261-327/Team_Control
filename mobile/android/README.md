# Android и серверное API

Приложение использует Django API сайта с базовым адресом из `API_BASE_URL` Gradle property. По умолчанию задан `https://sipi.prettiqs.workers.dev/api/`; для сборки под другой адрес можно передать `-PAPI_BASE_URL=https://ваш-домен/api/`.

Вход и регистрация используют серверный пароль, OTP-код по почте и Django session/CSRF cookies. Снимок `GET bootstrap/` заполняет проекты, задачи, участников, комментарии, историю и ссылки на материалы. Создание и изменение задач, статусы, комментарии, проекты, профиль, приглашения и ссылки на материалы отправляются серверу; после изменений приложение заменяет локальное состояние новым snapshot.

В этой ветке API дополнен маршрутом `PATCH projects/:id/settings/` для названия и описания проекта; `tasks/` и `tasks/:id/` также принимают пустой `assigneeId`, чтобы сохранить задачу без исполнителя. Эти изменения находятся в `backend/` этого репозитория. Сервер, на котором их ещё нет, нужно обновить и перезапустить/передеплоить, прежде чем использовать редактирование сведений проекта и назначение «без исполнителя».

Вкладка «Материалы» добавляет ссылки, потому что существующий API хранит URL, название и описание материалов, а не загруженные Android-файлы. Сезон проекта остаётся вычисляемым из даты создания и сервером отдельно не редактируется.
