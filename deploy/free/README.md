# Бесплатный облачный тестовый стенд Сипи

Основной вариант — [Vercel Services: интерфейс и Django в одном проекте](vercel-services.md). База остаётся в Neon, текст и картинки обрабатывает Cloudflare Workers AI, письма отправляет выбранный SMTP-провайдер или Brevo. Постоянно включённый компьютер и локальные модели не нужны.

[Вариант с отдельным Render](render.md) сохранён как запасной профиль, если Services Beta недоступен в выбранном проекте. Не смешивай настройки двух профилей: у Services корень Vercel — весь репозиторий, у Render-профиля Vercel собирает только `frontend`.

Конфигурация и тесты не заменяют публикацию. Для общего стенда ещё нужны аккаунты, ключи, подтверждённый отправитель писем, фактический адрес и проверка живого входа/ИИ. Бесплатные тарифы имеют квоты.
