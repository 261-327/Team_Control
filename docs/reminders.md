# Диагностическая проверка дедлайнов (BE-10)

Команда только читает БД и пишет JSON Lines в stdout. Письма не отправляются,
записи об отправке не создаются. Вывод содержит адреса исполнителей: не публикуйте
вывод рабочей БД. Пример получателя: developer@example.test.

```sh
cd backend
python manage.py preview_reminders
python manage.py preview_reminders --now "2026-11-16T12:00:00+03:00"
```

Используется существующий Task.due_date (в API deadlineAt), assignees и связь
Task → Column → Board → Project. Новых моделей и миграций нет.
Категории взаимоисключающие, в указанном порядке:

1. overdue: срок строго раньше now.
2. today: дата срока совпадает с датой now в Europe/Moscow; равенство now входит сюда.
3. within_48_hours: оставшийся срок не больше 48 часов включительно.

Нет срока или срок дальше окна — нет записи. Колонки is_completed и статус done
исключаются. Исполнитель должен быть активным, иметь email и подтверждённое участие
в этом проекте либо быть владельцем (используется is_project_member).
Для нескольких исполнителей выводится одна запись на каждого допустимого получателя;
одна задача не попадает в несколько категорий. Порядок: ID задачи, ID получателя.
--now принимает только timezone-aware ISO 8601. В выводе срок имеет смещение +03:00.

## Согласование

Единая функция диагностической классификации — tasks.reminders.reminder_kind.
На сайте frontend/src/lib/format.ts urgency использует скользящие 24/48 часов;
это не календарная категория «сегодня». Не заменяем существующее UI-поведение.
Границы этого прототипа заданы BE-10; согласование с ответственным за задачи
ещё требуется, не считаем его проведённым автоматически.

## Следующая итерация

Согласовать расписание и часовой пояс с командой, канал и текст реальных писем.
Спроектировать идемпотентность, журнал отправок, повторные попытки и поведение при
смене срока/исполнителя, удалении участия и завершении задачи. Проверять права
повторно непосредственно перед отправкой. Этот preview не является системой
доставки уведомлений ровно за 48 часов и не запускается по расписанию.
